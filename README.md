# MetroPT-3 ETL (individual work, CITS5553 Group 8)

Author: Rahul Thirumala Prakash (24611995)

## What this is
My ETL work for the group's predictive maintenance capstone:
- cleaning and checks on the MetroPT-3 sensor data
- a 30-minute pre-failure label and a rolling z-score "adaptive" label
- a chronological split (F1-F3 train, F4 test)

## Files
- Copy of MetroPT3_ETL.ipynb: the ETL notebook
- MetroPT3_ETL_Documentations.md: step-by-step explanation and handoff notes
